# GRASINT

GRASINT — настольная программа для проверки места и времени съёмки по фотографии.

> A local desktop tool for photo geolocation and verification: EXIF, map checks, SunCalc, OCR and reports.

GRASINT не обещает «найти место по одному клику». Он собирает признаки на снимке, сверяет их с картами, солнцем, надписями и внешними источниками и показывает, где версии совпадают, а где нет.

## Что это

Рабочий стол для проверки фото:

- метаданные и GPS;
- гипотезы нейросети по региону и городу;
- карта, панорамы и снимки улиц;
- проверка по солнцу и тени;
- распознавание надписей и поиск объектов в OpenStreetMap;
- погода, рельеф, дороги, растения;
- расследование по нескольким фото;
- граф связей и отчёт.

## Чего программа не делает

- не ищет человека по лицу;
- не следит за устройством и не читает переписки;
- не даёт гарантированный результат: проценты и совпадения — это вероятностная оценка;
- не заменяет Google Lens;
- не работает без сети там, где нужны карты, панорамы и сторонние API.

## Разделы программы

### Страна

Первый экран для фото и метаданных.

- загрузка фото, вставка из буфера, перетаскивание;
- чтение EXIF и проверка GPS;
- ограничение поиска страной, областью, городом или кругом;
- выбор покрытия дорог и растительности;
- запуск анализа и переход к гипотезам.

### Улица

Карта и проверка конкретной точки.

- встроенная карта, OSM, Overpass, Street View;
- Mapillary: похожие снимки улиц;
- публичные камеры рядом;
- поиск адреса и объектов вокруг точки;
- подстановка найденной точки в анализ;
- сохранение результата в историю.

### Авто

Автоматический проход по цепочке:

```text
переписка → EXIF → GeoCLIP → SunCalc → погода → местность → дороги
→ OCR → POI → Mapillary → камеры → Google Lens/веб-поиск → растения
→ граф и отчёт
```

Что можно включить галочками:

- **Mapillary + камеры**;
- **Google Lens и веб-поиск**;
- **Растения (PlantNet)**.

Что важно знать:

- стоимость запуска — 10 токенов;
- на free-тарифе «Авто» доступно один раз в неделю;
- Google Lens открывает видимое окно браузера и может требовать капчу;
- если солнце не сходится ни с одной гипотезой, результат не выдумывается: остаются только внешние адреса или «не определено».

### Что на фото

Поиск места по признакам застройки.

- этажность, материал, крыша;
- что видно рядом: больница, аптека, банк, кафе, отель, вокзал, ТЦ, рынок;
- свои объекты: `Lotte Mart`, `школа №5`;
- допуск по этажам;
- сравнение городов-кандидатов.

### Погода

Определение погоды по фото.

- ясно, облачно, дождь, снег, туман, гроза;
- температура диапазоном;
- ветер по шкале Бофорта;
- сезон и время суток;
- уверенность и визуальные признаки.

По одной фотографии нельзя измерить точную температуру или скорость ветра. Программа показывает диапазон и честно пишет «не определить», если признаков мало.

### Дорога

Дороги, мосты, развязки, железнодорожные пути, станции и переезды.

- поиск объектов в OpenStreetMap вокруг точки;
- распознавание типа сцены по фото;
- переключатель «Дорога / ЖД».

### Местность

Рельеф и вода.

- равнина, холмы, горы;
- море, река, озеро, берег;
- сравнение линии горизонта и воды с картой высот;
- подсказки, где бывает такой рельеф;
- каталог растений и ареалы.

### Солнце и тень

Проверка времени и места по солнцу.

- дата, время и часовой пояс;
- высота и азимут солнца;
- длина тени и отношение тень/высота;
- отсечение регионов, где солнце не сходится;
- ручная разметка столба и тени.

SunCalc может опровергнуть гипотезу, но не доказать её: похожее солнце бывает во многих местах.

### Расследование

Несколько фото одного места.

- 5–20 снимков;
- общие кластеры кандидатов;
- GPS весит больше, гипотезы нейросети — меньше;
- общие надписи, найденные на нескольких фото;
- один общий граф на всё расследование.

### Граф связей

Граф собирает всё, что уже посчитано, в одну схему.

- в центре — фото;
- вокруг — разделы: анализ, что на фото, авто, улица, погода, дорога, местность, солнце, EXIF, надписи;
- под анализом и погодой — страны, области и города-кандидаты;
- у города видно балл, солнце и другие проверки;
- клик по разделу открывает соответствующую вкладку;
- клик по городу открывает карту;
- колесо мыши масштабирует, левая кнопка перетаскивает, «Вписать» показывает всё целиком;
- разделы можно сворачивать и раскрывать;
- правый клик по вкладке фото — переименовать или удалить граф.

Если раздела не было в анализе, узел честно пишет «нет данных». Это не ошибка: граф не досчитывает то, что не запускали.

### Отчёт

Два вида отчёта.

**«Сохранить дело…» в Авто** — один self-contained HTML:

- встроенные фото и кадры видео;
- SHA-256 исходников;
- кандидаты и вклады;
- что отсекло и почему;
- сверка времени и погоды;
- карта вероятностей;
- источники;
- дополнительные проверки: Mapillary, камеры, веб-поиск, растения.

**Вкладка «Отчёт»** — экспорт:

- HTML;
- KML;
- CSV.

Перед публикацией отчёта проверьте, нет ли в нём личных данных: история и логи хранят метаданные и распознанный текст.

### EXIF

Метаданные фото.

- камера, модель, объектив, дата;
- GPS и его проверка;
- следы редактирования;
- подозрительные или противоречивые поля.

### Логи

Журнал работы приложения.

- загрузка моделей;
- сетевые ошибки;
- ход анализа;
- предупреждения;
- фильтр по подсистемам.

Названия внутренних моделей в логах обезличены: пишется `ИИ-модуль`, а не конкретная модель.

### Настройки

- токены и ключи API;
- скачивание моделей;
- поиск и проверка;
- данные и приватность;
- самоочищение истории и логов: 1 день / неделя / месяц / не удалять;
- политика конфиденциальности;
- обновление приложения;
- поддержка и отзывы.

### Профиль

- KEYPID и тариф;
- остаток онлайн- и офлайн-токенов;
- срок действия;
- QR для входа с телефона;
- последние открытия;
- выход.

## Приватность

- фотографии и история анализов по умолчанию хранятся локально;
- историю и логи можно выключить, зашифровать и очистить;
- есть офлайн-режим;
- API-ключи хранятся только в локальном файле настроек;
- сторонние сервисы используются только при выборе соответствующей функции;
- полная политика — в программе: **Настройки → Политика конфиденциальности**.

Сторонние сервисы, которые могут получать запросы: OpenStreetMap/Overpass/Nominatim, Mapillary, Wikimedia Commons, Open-Meteo, OpenSky, Windy, PlantNet, OCR.space, Google и Яндекс (через видимое окно браузера).

## Установка из исходников

Нужен Python 3.10+ (рекомендуется 3.12).

```bash
git clone https://github.com/USER/GRASINT.git
cd GRASINT
python install.py
python run.py
```

Полезные параметры:

```bash
python install.py --proxy http://127.0.0.1:7890
python install.py --pip-index https://pypi.org/simple
python install.py --no-ocr
python install.py --model
python install.py --no-model
```

Запуск с консолью:

```bash
python run.py --console
```

## Требования

- Linux или Windows;
- 8 ГБ RAM минимум, 16 ГБ рекомендуется;
- 10–15 ГБ на диске под модели;
- GPU не обязательна, но на CPU анализ медленнее;
- интернет для скачивания моделей и сетевых проверок.

## Где лежат данные

Настройки:

```text
Linux:   ~/.config/GRASINT/config.json
Windows: %APPDATA%\GRASINT\config.json
```

Рабочие данные — рядом с программой:

```text
history/   история анализов
logs/      логи
cache/     кэш
reports/   отчёты
models/    модели
```

Историю можно зашифровать. Ключ истории лежит в папке настроек с правами `600`.

## Сборка релиза

```bash
python tools/build_release.py --target arch
```

Релиз компилируется Cython в нативные `.so`; `.py`-исходники в релиз не попадают. Установщик собирается отдельно:

```bash

```

## Ограничения

- нейросеть геолокации часто ошибается на уровне города;
- SunCalc отсекает версии, но не доказывает место;
- тень по фото измеряется с погрешностью из-за перспективы;
- сходство Mapillary — повод проверить глазами, а не доказательство;
- Google Lens может не отдать результаты без браузера, сети или без прохождения капчи;
- часть моделей тяжёлая, первый запуск на CPU может быть долгим.
